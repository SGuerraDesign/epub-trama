# EPUB Trama

Editor de eBooks para Windows: cria livros digitais em **EPUB 3** prontos para o **Amazon KDP**, de texto fluido (romance, não ficção, técnico) e de layout fixo (infantil ilustrado, fotografia, quadrinhos, didáticos).

**Site do programa:** <https://epubtrama.sguerra.com.br>

## Baixar

O instalador da versão mais recente está em **[Releases](https://github.com/SGuerraDesign/epub-trama/releases/latest)**: baixe o arquivo `EPUB-Trama-Setup-<versão>.exe` e abra-o.

- Windows 10 e 11 (64 bits).
- Na primeira execução o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.
- Cada release traz o SHA-256 do instalador, para quem quiser conferir o arquivo baixado.
- Depois de instalado, o próprio programa avisa quando há versão nova.

## Sobre este repositório

Este repositório guarda apenas os instaladores do programa. O código-fonte não é público.

O uso do programa segue os [termos de uso](https://epubtrama.sguerra.com.br/termos.html).
